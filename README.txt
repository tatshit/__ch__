# Мой прогресс — Android PWA

## Что внутри
- Ежедневные привычки с отметками и XP
- Уровни, серия дней и достижения
- Календарь активности и месячная статистика
- Добавление и удаление собственных привычек
- Сохранение данных на устройстве в браузере
- Поддержка установки на главный экран и офлайн-режима после первой загрузки

## Как установить на Xiaomi Mi 9 Pro
PWA устанавливается через защищённый HTTPS-адрес. Самый простой способ:
1. Распакуй архив на компьютере.
2. Загрузи содержимое папки в новый GitHub-репозиторий (можно включить GitHub Pages в Settings → Pages → Deploy from a branch → main / root).
3. Открой получившийся HTTPS-адрес на телефоне в Chrome.
4. В меню Chrome выбери «Установить приложение» или «Добавить на главный экран».
5. Запусти «Мой прогресс» с появившейся иконки.

## Важно
Данные хранятся локально в браузере на телефоне. Не очищай данные сайта/Chrome, иначе отметки могут пропасть. Для переноса на другой телефон понадобится отдельная функция резервного копирования — её можно добавить следующим этапом.
